# Lecture 2: 比例尺、金额概念与极简细节

## Learning Goals

- 区分“进度条”“刻度尺”“仪表”三种不同的界面物。
- 理解为什么金额轴必须使用对数感，而不是线性感。
- 学会用极少的平面元素同时表达数量、区间、阈值和判断压力。
- 把课程判断落实到《钱就是钱》的竖向金额轴，而不是停留在审美意见。

## Opening Problem

现有金额轴已经比普通滑条更大，也能拖动，但它还没有完全成为一把“钱的尺”。它主要依赖两种信号：

- 左边红色意味着“容易被带走”。
- 右边绿色意味着“更可能是真的”。

这能表达方向，但不能表达尺度。用户看到 648、2999、15000 时，应该不仅知道“更大了”，还应该直觉地感到：这笔钱从咖啡、会员、抽卡，进入了工具、机器、余地和选择权的区域。比例尺不是装饰，它是产品的认识论。

## Core Concepts

### 1. 进度条、刻度尺、仪表

- Definition: 进度条表达完成度；刻度尺表达可读数；仪表表达读数、危险区、阈值和操作反馈的组合。
- Why it matters: 《钱就是钱》不是“从少到多”的动画，而是帮助用户重新校准金额感。
- Example: 648 元不是 15000 元的 4.32%，它在生活感里是一次强刺激消费、一次椅子、一段回家路、几次体检项目的交汇点。
- Common mistake: 把竖向金额轴做成好看的渐变滑条，导致它像情绪条，不像可以信任的尺。

### 2. 对数尺的伦理

- Definition: 对数尺让小金额有足够空间被看见，同时避免大金额把前面的生活细节全部压扁。
- Why it matters: 1 元到 30 元、30 元到 648 元、648 元到 15000 元都重要，但重要方式不同。
- Example: 咖啡和网盘会员在 30 元附近应该被展开；手机和电脑在几千元附近应该被并置；余地钱在万元以上应该让人感到“选择权”的重量。
- Common mistake: 线性尺看似客观，实际会让绝大多数日常消费挤在底部，看不见。

### 3. 价格带作为视觉房间

- Definition: 价格带不是标签，而是用户进入不同金额语义的房间：零钱、小仪式、一晚、一天、周末、工具、余地。
- Why it matters: 用户拖动时需要知道自己跨过的是生活类型，不只是数字。
- Example: 599 到 2999 被称为“周末钱”，因为它既可以是抽卡，也可以是回家、椅子、课程、作品和短途出走。
- Common mistake: 把价格带只写在文案里，导致用户必须读字才理解；好的轴应该先用结构给出感觉。

### 4. 极简细节的标准

- Definition: 极简不是少，而是每个元素都承担一个清楚的任务。
- Why it matters: 这个产品不能变成理财仪表盘，也不能变成鸡汤海报。
- Example: 一条中轴表达金额的量感；浅色价格带表达区间；不同长度的刻度表达阈值；左右标注表达同价位的注意力/真实选项。
- Common mistake: 为了“高级”而去掉刻度、标签和反馈，使用户失去校准感。

## Demonstration / Case

以 648 元为例：

```text
不是：
648 在绿色和红色之间某个位置。

而是：
648 位于“周末钱”的入口附近。
左侧可能是原神 648、直播间套装、节日限定皮肤。
右侧可能是人体工学椅、近程高铁票、心理咨询、认真课程。
它比咖啡更像一个决定，比手机又更像一次注意力风暴。
```

因此金额轴要同时完成四个动作：

1. 让当前金额永远被读到。
2. 让相邻金额带的边界能被感觉到。
3. 让关键刻度有不同权重。
4. 让左/右两侧的物品标注不遮住金额读数。

## Techniques

| Technique | How To Use It | Failure Mode |
| --- | --- | --- |
| 对数空间 | 用 `priceToPercent` 把价格映射到垂直位置，让日常小额和大额目标都可读 | 用户不知道为什么间距不均匀 |
| 价格带水印 | 把“零钱/小仪式/周末/工具/余地”做成轨道内部的淡层 | 标签太响，像解释贴纸 |
| 阈值刻度 | 让 33、299、648、2999、15000 等关键点比普通刻度更有重量 | 所有刻度一样粗，无法形成层次 |
| 中性量感中轴 | 中间主轴表达金额大小，不承担红绿道德判断 | 颜色只剩红绿，金额概念被情绪吞掉 |
| 当前读数避让 | 当前金额卡片靠近中轴，但在顶部/底部自动换方向 | 大金额被轨道遮住，或读数跳动 |

## Recap

- 比例尺不是“把价格放上去”，而是定义用户如何理解价格。
- 《钱就是钱》的竖轴应当像一件小仪器：可拖、可读、可校准、可产生顿悟。
- 最小可行改动不是增加模块，而是让轴内部出现价格带、阈值刻度和更中性的金额量感。
