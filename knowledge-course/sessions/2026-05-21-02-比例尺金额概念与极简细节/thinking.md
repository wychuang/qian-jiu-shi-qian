# Thinking Record 2: 比例尺、金额概念与极简细节

## Instructor Choices

- 把批评的焦点从“哪里不好看”改写为“这把尺缺少哪些读数职责”。
- 不把课程变成泛泛的 UI 审美课，而是训练一种工业设计判断：控件必须让用户更准确地理解世界。
- 选择最小但核心的产品改动：不新增页面，不新增故事模块，只重做金额轴内部的信息结构。

## Concept Map

```text
金额轴
  -> 对数映射：让小钱和大钱都能被看见
  -> 价格带：把金额变成生活尺度
  -> 阈值刻度：让关键金额有重量
  -> 当前读数：让操作反馈稳定可信
  -> 左右物品针脚：让同价位替代消费出现
  -> 中性主轴：表达金额大小，而非道德判断
```

## Tensions

- 轻 vs 空：产品不重，但不能轻到没有仪器感。
- 极简 vs 信息密度：不能堆文案，但可以让结构承载更多信息。
- 情绪色 vs 金额材料：红绿可以服务左右判断，中轴需要服务数量感。
- 准确 vs 启发：价格不是实时数据库，但轴的尺度必须让人信任。

## Speculative Notes

- “钱的重量”可以通过线宽、刻度长度、底纹密度和颜色沉降表达，而不一定通过更多文字表达。
- 用户拖动金额时，如果感觉像在移动一枚读数指针，而不是拖一个网页滑条，产品的“金钱观重建”会更成立。
- 价格带标签可以是半隐形的：用户第一次不一定读全，但多看几次会发现它们一直在那里。

## Questions To Carry Forward

- 物品针脚是否应该在当前金额附近形成更明显的左右拉力？
- 是否需要让用户自定义自己的价格带名称，例如“我的周末钱”“我的工具钱”？
- 美国版本的金额带是否需要更强的住房、医疗和交通锚点？
