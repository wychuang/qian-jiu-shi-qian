# Homework 2: 比例尺、金额概念与极简细节

## Retrieval

1. 不看讲义，用自己的话区分“进度条”“刻度尺”“仪表”。
2. 解释为什么《钱就是钱》的金额轴适合对数尺度，而不是线性尺度。
3. 写出三个价格带，并说明它们分别对应什么生活感。

## Application

1. 打开当前网页，分别观察 30、648、2999、15000 元附近：记录每个点你首先感到的是“数字”“物品”“区间”还是“压力”。
2. 选择一个点，设计一个只用线条、刻度、淡色块表达的微改动，不能增加新的说明卡片。

## Comparison

1. 比较“红绿渐变轴”和“价格带刻度轴”：前者表达了什么，后者表达了什么？
2. 比较“把价格带写在文案里”和“把价格带做进轨道里”：哪一种更像工业产品？

## Transfer

1. 把同样方法转移到一个非金钱界面：睡眠时间、电动车续航、学习进度或项目风险。说明它的“价格带”对应什么。

## Observation

1. 找一个真实 App 或实体产品的刻度设计，拍脑内截图：它的主刻度、副刻度、危险区和当前读数分别在哪里？
2. 记录一个失败案例：某个界面明明有数字，却让你不相信或不理解它。

## Reflection

1. 写 150 字：这节课之后，你对“轻量”这个词的理解有什么变化？
2. 写一句给产品的判断标准：以后如果要继续改金额轴，什么改动应该被拒绝？

## Rubric

| Level | Description |
| --- | --- |
| Strong | 能把比例尺的职责说清楚，并提出结构性改动，而不是只说好不好看。 |
| Developing | 能解释对数尺和价格带，但改动仍偏装饰或文案。 |
| Needs Work | 只重复“更直观”“更高级”，没有指出哪个元素承担哪个任务。 |
