# Lecture 1: 工业设计视角下的价值轴产品

## Learning Goals

- 理解为什么《钱就是钱》更像一台仪器，而不是一个普通网页。
- 学会用“控制、读数、映射、反馈、约束、容错”评价界面。
- 能指出金额轴当前做对的地方和仍然脆弱的地方。
- 能把工业设计的知识迁移到其他工具型产品。

## Opening Problem

用户之前连续指出几个问题：拖动不舒服、默认金额弹回、价格轴没有打磨、大金额藏到进度条后面、页面内容像狗皮膏药。这些不是孤立的 CSS 问题，而是工业设计里的典型问题：控制件没有形成稳定的操作模型，读数没有获得足够的空间尊严，界面的状态反馈没有让用户建立信任。

工业设计关心的不是“这个东西漂不漂亮”，而是“人在使用它时，身体、眼睛、判断和反馈是否形成闭环”。一把门把手、一台血压计、一个相机拨盘、一个网页金额轴，本质上都要回答类似问题：我能不能看出它能做什么？我做了动作以后，它有没有稳定回应？极端情况下它会不会失控？它有没有让我更清楚，而不是更累？

## Core Concepts

### 1. 界面作为仪器

- Definition: 仪器是一个可操作、可读数、可校准的对象。它不只是展示信息，而是帮助用户改变观察位置。
- Why it matters: 《钱就是钱》的核心不是展示商品，而是让用户拖动金额，改变观察点，看见同一笔钱的不同可能性。
- Example: 竖向金额轴像价格标尺；当前金额是读数；左右两侧是“注意力消费”和“更可能是真的”的语义泳道。
- Common mistake: 把金额轴当成装饰性进度条，只追求视觉存在感，不保护读数和反馈。

### 2. 控制、读数、反馈三角

- Definition: 控制是用户改变状态的部件，读数是系统状态的可见表达，反馈是动作后的即时回应。
- Why it matters: 用户拖动金额时，必须同时看到金额改变、焦点项变化、同价位意义变化。
- Example: `vertical-slider` 是隐藏的控制层，`.rail-current` 是当前读数，焦点卡和左右 pin 是反馈。
- Common mistake: 控制和读数粘在一起，导致标签、刻度和当前金额互相遮挡。

### 3. 映射

- Definition: 映射是动作方向和意义方向之间的关系。
- Why it matters: 竖向轴天然让人期待“越上越大”或“越上越重要”。如果价格、标签和内容不稳定，用户会觉得轴不可信。
- Example: 当前实现用对数价格映射，把 1 元到 150000 元压进一条可拖动的轴；低价和高价都能出现。
- Common mistake: 只按线性价格放置，导致低价全部挤在底部，高价占满空间。

### 4. 约束与容错

- Definition: 约束减少错误操作；容错保证边界状态仍然可用。
- Why it matters: 这个产品有许多边界：小屏幕、长金额、长标题、品牌标签、用户拖拽、模式切换。
- Example: 大金额读数用 `data-size` 降字号；当前金额读数保留专门空间；模式按钮限定为 `button[data-mode]`。
- Common mistake: 只看默认 `¥648` 的漂亮截图，不测试 `¥1.00`、`¥36,000`、`¥150,000`。

### 5. 语义密度

- Definition: 一个界面元素承载的意义量和清晰度之间的平衡。
- Why it matters: 《钱就是钱》不能把所有解释摊开，否则轻量感会消失；但也不能只有价格和名称，否则不会启发。
- Example: 焦点项集中呈现“一句话意义 / 买到什么 / 同价位也许是 / 反思问题”，其它卡片保持短。
- Common mistake: 把每个卡片都做成小作文，让用户在理解金钱之前先被文字淹没。

## Demonstration / Case

以 `¥648` 为例。

用户的直觉入口可能是“原神 648”。如果界面只是告诉他“这是注意力消费”，它就是道德批评；如果界面把它放在价值轴上，同时让人体工学椅、心理咨询、近程高铁、驾照报名出现在同一视野里，它就从批评变成校准。

工业设计视角会追问：

1. 用户能不能立刻知道这条轴可以拖？
2. 拖动时当前金额是否像仪表读数一样稳定？
3. 左右两侧标签是否解释了不同方向的意义？
4. 焦点卡是否回应了当前状态，而不是像旁边的一篇文章？
5. 当金额变成 `¥36,000` 或 `¥150,000` 时，这台仪器是否仍然可信？

这五个问题比“颜色好不好看”更基础。

## Techniques

| Technique | How To Use It | Failure Mode |
| --- | --- | --- |
| 控制-读数分离 | 给拖动热区、当前读数、刻度标签不同层级和空间。 | 当前金额被普通刻度挤掉，用户不知道状态。 |
| 布局容差表 | 列出最短/最长金额、最长标题、小屏幕、宽屏、模式切换并逐一验收。 | 默认状态很好看，一到边界就破。 |
| 一屏一任务 | 默认模式只让用户完成“看清这笔钱”。 | 把画像、清单、对照全摊开，主动作失焦。 |
| 同价位横跳 | 让同一笔钱跨到身体、关系、工具、未来余地。 | 跨界太随机，变成猎奇列表。 |
| 语义压缩 | 把复杂解释压缩成一行意义，把细节放到焦点项。 | 文案过短会空，过长会糊。 |

## In-Class Exercise

看当前产品第一屏，用三个颜色在纸上标注：

1. 哪些东西是控制？
2. 哪些东西是读数？
3. 哪些东西是解释？

如果一个元素同时承担三种角色，它就有潜在风险。金额轴可以复杂，但角色必须清楚。

## Recap

- 《钱就是钱》的工业设计核心是“认知仪器”，不是“价格列表”。
- 好的仪器必须保护读数，建立映射，提供反馈，处理边界。
- 产品越想轻，越要把主动作和必要反馈做扎实。
- 下一轮真正值得打磨的不是更多装饰，而是更强的可供性和更好的语义校准。
