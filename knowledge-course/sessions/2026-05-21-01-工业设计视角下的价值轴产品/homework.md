# Homework 1: 工业设计视角下的价值轴产品

## Submission Form

请把作业写成一个 Markdown 文件，建议命名为：

```text
knowledge-course/sessions/2026-05-21-01-工业设计视角下的价值轴产品/user-homework.md
```

不用追求长，但要具体。每题至少写一个来自《钱就是钱》的例子。

## Retrieval

1. 不看讲义，用自己的话解释这六个词：控制、读数、映射、反馈、约束、容错。
2. 为什么说《钱就是钱》更像“认知仪器”，而不是“价格列表”？
3. “轻量”和“简陋”的区别是什么？请用当前产品举例。

## Application

1. 打开产品默认页，找出三个控制、三个读数、三个解释元素。说明它们是否混淆。
2. 把金额分别拖到小额、中额、大额。记录你看到的视觉变化，并判断哪一个状态最像仪器，哪一个最像网页。
3. 选择一个焦点项，例如“原神 648 创世结晶”或“MacBook Air”。写出它的同价位横跳是否有内在联系。

## Comparison

1. 区分“比较”和“审判”：当前产品哪一句文案是在比较，哪一句可能被理解成审判？
2. 区分“真实消费”和“便宜消费”：举一个不便宜但可能很真的消费，再举一个便宜但不一定真的消费。
3. 区分“仪器感”和“金融感”：这个产品需要哪一部分金融感？又应该避免哪一部分金融感？

## Transfer

1. 把“控制-读数-反馈”框架迁移到一个实体产品，比如电梯、微波炉、相机、洗衣机或血压计。
2. 把“同价位横跳”迁移到一个非金钱领域，比如时间管理、饮食、学习或社交。
3. 如果你要做“时间就是时间”，它的主轴、左右语义和焦点卡会是什么？

## Observation

1. 在现实生活中观察一次 100 元以内的消费冲动。记录：当时的触发、它承诺买到什么、同样的钱还可以变成什么。
2. 找一个你觉得“读数很舒服”的实体或软件界面。描述它如何处理控制、读数和反馈。
3. 找一个你觉得“不知道怎么用”的产品界面。指出它缺少的是可供性、映射、反馈还是约束。

## Studio Task

画一个低保真草图，不需要好看。要求：

1. 只画默认价值轴模式。
2. 标出当前金额读数、拖动热区、注意力标签、更真标签、焦点项。
3. 给 `¥648`、`¥36,000`、`¥150,000` 三个金额状态各画一个小版本。
4. 写一句话说明：你的草图如何避免大金额遮挡。

## Reflection

1. 学完这节课后，你对《钱就是钱》的看法有什么变化？
2. 你觉得当前产品最像仪器的地方在哪里？最不像的地方在哪里？
3. 如果只能改一个点，让它更符合工业设计标准，你会改什么？为什么？
