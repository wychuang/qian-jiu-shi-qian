# Thinking Record 1: 工业设计视角下的价值轴产品

## Instructor Choices

- 我选择从“仪器”而不是“界面美化”讲起，因为用户之前的不满集中在拖拽、金额回弹、价格轴不合理、大金额遮挡，这些都属于控制和读数问题。
- 我没有把课程变成“如何继续改这个网页”的任务清单，而是先建立可迁移的工业设计语言。这样下一次讨论别的产品时，仍然能使用这套框架。
- 我保留了对当前产品的批评：它已经接近仪器，但还没有完全摆脱网页卡片感。
- 我把“真假消费”的语言视为设计张力，而不是默认正确。它有力量，也有伤人的风险。

## Concept Map

```text
钱就是钱
  -> 认知仪器
    -> 控制: 竖向金额轴
    -> 读数: 当前金额 / 焦点项 / 价格带
    -> 映射: 价格对数尺度 / 上下方向 / 左右语义
    -> 反馈: pin / focus card / equivalence set
    -> 约束: 三模式 / scoped buttons / selectedId 清空
    -> 容错: 大金额字号 / label spacing / mobile layout
  -> 情绪温度
    -> 不羞辱
    -> 不放任
    -> 清醒但有余地
  -> 内容真实感
    -> 中国年轻人品牌锚点
    -> 同价位横跳
    -> 生活后果而非价格分类
```

## Tensions

- **仪器感 vs 人味：** 越像仪器，越清晰；但过冷会像财务审判工具。产品需要一点生活观察的温度。
- **真实判断 vs 道德评判：** “更可能是真的”很有力，但容易滑向“你买错了”。需要通过文案和内容保持开放。
- **具体品牌 vs 长期有效：** 原神 648、AirPods、MacBook 提供真实锚点，但品牌和价格会变化。目录需要定期修订，同时不能变成实时数据库。
- **轻量 vs 完整：** 用户想要轻，但“金钱观重建”本身很深。解决方式不是减少思想，而是把思想压进一个清晰动作。
- **探索地图 vs 精密仪表：** pin 越多越有发现感，越少越有读数感。不同模式也许应该承担不同密度。

## Speculative Notes

- 也许下一版可以把“真假”从二元方向改成三种留下来的东西：身体、能力、余地。这样会降低道德感，但可能削弱冲击力。
- 当前焦点卡可以更像“读数面板”：显示这笔钱变成了什么、留下多久、牺牲了什么，而不只是标题和详情。
- 用户自定义“我的真东西”可能是关键，但一旦加入账户或本地存储，产品会变重。可以先用无保存的临时清单试探。
- 价值轴可以增加极轻的“吸附点”手感，让 648、2999、8499 等文化价格锚点更像真实刻度。

## Questions To Carry Forward

- 什么样的视觉语言能表达“清醒”，但不表达“审判”？
- 当前卡片里的 truthScore 是否应该被用户看见，还是只用于排序？
- 金额轴是否需要更明显的拖动把手，还是当前圆形读数已经足够？
- 对照模式是否应该从“列表”转成“同价位桌面”，像把物品摆在桌上一样比较？
- 课程下一节是否应该让用户亲自做一次工业设计标注作业，再基于作业改界面？
