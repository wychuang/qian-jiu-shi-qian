# Course Syllabus: 工业设计与认知工具

## Course Purpose

这门课把《钱就是钱》当成一个工业设计对象来研究：它不是一张网页，也不是一组卡片，而是一台帮助人重新校准消费判断的认知仪器。课程目标不是立刻改代码，而是学习一套更宽泛的设计知识：如何让控制、读数、反馈、约束、容错、语义密度和情绪温度共同组成一个可靠的产品。

## Course Contract

- 这门课不以某个即时功能为唯一目标。
- 每节课都必须留下讲课记录、讨论记录、思考记录、作业记录和综合记录。
- 课程地图会随着我们对产品和知识的理解逐渐丰满。
- 如果之后改产品，改动应来自课程中形成的判断，而不是临场审美冲动。

## Module Map

| Module | Theme | Status |
| --- | --- | --- |
| 1 | 仪器感：控制、读数、映射、反馈 | active |
| 2 | 可供性与约束：用户如何知道能做什么 | planned |
| 3 | 语义密度：少量界面承载大量判断 | planned |
| 4 | 容错与边界：大金额、小屏幕、误触和视觉挤压 | planned |
| 5 | 情绪温度：不羞辱、不说教、但足够清醒 | planned |
| 6 | 设计评审工作坊：从作业进入改版方案 | planned |

## Evaluation Style

- **理解：** 能用自己的话解释工业设计概念，而不是背术语。
- **应用：** 能把概念用在《钱就是钱》的具体界面上。
- **比较：** 能区分“好看”“可用”“可信”“有启发”。
- **迁移：** 能把同一套方法用到别的工具、表单、仪表盘或实体产品。
- **反思：** 能说清楚自己的产品判断如何改变。

## Open Questions

- 价值轴怎样保持启发性，同时避免变成道德审判轴？
- 金额读数、商品标签和焦点卡之间，谁应该拥有第一视觉优先级？
- “轻”是否意味着功能少，还是意味着决策路径短？
- 中国年轻人的真实消费锚点如何持续更新，而不让产品变成购物数据库？
